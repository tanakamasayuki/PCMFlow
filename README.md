# PCMFlow

Lightweight audio decode and PCM flow library for Arduino.

PCMFlow decodes audio input and produces formatted PCM data (8-bit unsigned / 16-bit signed, mono/stereo) into an internal ring buffer. It is independent of any specific output device, codec, file system, network stack, OS, or RTOS task model.

See [SPEC.ja.md](SPEC.ja.md) for the full specification (Japanese).
